# PonteVisible Pro

**Hazte visible. Conecta. Crece.**

Plataforma B2B de red de negocios para que tu empresa sea visible, conecte con clientes empresariales y particulares, y crezca con analítica avanzada.

## 🚀 Stack Tecnológico

- **Frontend**: React 19 + Vite 8 (SPA)
- **Backend**: Supabase (PostgreSQL, Auth, RLS, Storage)
- **Estilos**: CSS Modules / CSS-in-JS con sistema de diseño propio
- **SEO**: react-helmet-async, Open Graph, Twitter Cards, JSON-LD

## 📦 Instalación

```bash
npm install
```

## ▶️ Desarrollo

```bash
npm run dev
```

## 🏗️ Build de producción

```bash
npm run build
```

## 🔑 Variables de entorno

Copia el archivo `.env` con las siguientes variables:

```
VITE_SUPABASE_URL=tu_url_de_supabase
VITE_SUPABASE_ANON_KEY=tu_clave_anonima
```

## 🧩 Módulos

- **Identity**: Gestión de usuarios y roles
- **Organizations**: Multiempresa y sucursales
- **Business Profile**: Metadatos del negocio
- **Catalog**: Productos, servicios y categorías
- **Smart Storefront**: Vitrina inteligente para clientes
- **Search**: Búsqueda avanzada
- **Growth Center**: CRM y Marketing
- **Trust**: Reseñas y verificación
- **AI Engine**: Agentes y prompts versionados
- **Analytics**: Oportunidades Comerciales Generadas (OCG)
- **Platform Administration**: Billing y configuración
